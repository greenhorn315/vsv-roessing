# Bilder

Hier gehören die Fotos der Website hinein. Solange eine Datei fehlt, zeigt die
Seite automatisch einen gestalteten Platzhalter – es erscheint **kein** kaputtes
Bild-Symbol.

| Datei | Format | Empfehlung |
|---|---|---|
| `hero.jpg` | Hochformat 4:5 | ca. 800 × 1000 px |
| `social-1.jpg` … `social-4.jpg` | quadratisch | mind. 400 × 400 px |
| `og-default.png` (in `public/`) | 1200 × 630 px | Vorschaubild für WhatsApp/Facebook |

**Bitte beachten**

* JPG oder WebP, jeweils unter ca. 300 KB.
* Bei Fotos von Kindern und Jugendlichen ist eine schriftliche Einwilligung der
  Erziehungsberechtigten nötig (Recht am eigenen Bild, KUG/DSGVO), bevor die
  Bilder online gehen.
